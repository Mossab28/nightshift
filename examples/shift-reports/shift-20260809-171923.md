**Root cause (single, verified):** Upstream Snowflake `order_entry_db.order_entry.orders` renamed `order_total` → `order_amount`. The **deployed** dbt `order_details` model still selects `o.order_total` → NULLs → `SUMX(order_total)` in the PowerBI `Essential_KPI_Measures` sums to zero. Both reads confirm: the orders schema has only `order_amount` (description literally says "renamed from order_total"), and the deployed model logic still says `o.order_total`.

**Fix:** In dbt `order_details`, change `o.order_total` → `o.order_amount AS order_total`, rebuild, backfill last week's window.

**The real problem is process, not SQL:** this exact alias fix was issued on two prior nights and never stuck in prod - the upstream refactor branch keeps shipping without it.
