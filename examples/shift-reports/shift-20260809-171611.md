## Morning report — revenue dashboard zeroed

**Started from memory.** Previous night already diagnosed this exact break (incident c9f3ffe7): silent rename `order_total` → `order_amount` on `order_entry_db.order_entry.orders`. Two verification calls confirmed it explains tonight: the Snowflake source only has `order_amount` (annotated "renamed in an upstream refactor"), and the **deployed** dbt `order_details` model still selects `o.order_total`. Nulls flow into `order_details.order_total`; PowerBI's `SUMX` sums nulls to zero. Root cause in ~4 minutes.

**Why it broke again:** this is a recurrence — the alias fix from the prior incident never stuck in prod. The change that landed tonight is the refactored `orders` table hitting this environment.

**Fix (one line, in dbt model `order_details`):**
